# MMA/UFC новостной бот

Каждые 15 минут берёт свежие новости из RSS (Championat, FightNews, MMA Fighting, MMA Mania, Sherdog, ESPN MMA, UFC.com),
бесплатный Google Gemini переписывает их в короткий пост на русском, бот публикует в канал с фото из статьи и ссылкой на источник (если фото не загрузилось — пост уходит текстом).
Не больше 3 постов за проверку; реклама/ставки пропускаются.

## Настройка (один раз)
1. В Telegram открой @BotFather → `/newbot` → получи токен.
2. Добавь бота в свой канал **администратором** с правом публиковать сообщения.
3. Получи бесплатный ключ Gemini: https://aistudio.google.com/apikey (вход через Google-аккаунт, карта не нужна).
4. `cp .env.example .env` и впиши токен, `@канал` и ключ.

## Запуск
```bash
python3 bot.py
```
Работает, пока открыт терминал и Mac не спит. Один прогон без цикла: `bot.py --once`.
Первый запуск публикует только 1 новость, остальные текущие помечает как прочитанные.

Проверка без ключей: `python3 test_bot.py`.

Источники, частота и лимит постов — в начале `bot.py` (`FEEDS`, `INTERVAL_MIN`, `MAX_POSTS_PER_RUN`), текст для нейросети — `PROMPT`, модели — `GEMINI_MODELS` (сильная, а если перегружена — лёгкая).
